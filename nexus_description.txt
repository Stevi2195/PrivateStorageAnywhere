[size=4][b]Private Storage Anywhere[/b][/size]

[line]

Open your Private Storage (Camp Warehouse) from anywhere in the world with a single hotkey or controller button press. No need to walk back to your camp chest.

[line]

[size=3][b]Features[/b][/size]

[list]
[*][b]F6[/b] to open Private Storage from anywhere on the map
[*][b]ESC[/b] to close (or F6 again)
[*][b]Native UI:[/b] Uses the game's built-in warehouse interface — no custom overlay
[*][b]Localized titles:[/b] Warehouse title automatically matches your game language (14 languages supported)
[*][b]Full interaction:[/b] Move items in and out of storage, same as at the chest
[*][b]No chest visit required:[/b] Works immediately after game start
[*][b]Update-proof:[/b] Uses automatic pattern scanning and vtable matching to locate internal game functions instead of relying on hardcoded offsets
[*][b]Compatible with UI mods:[/b] Identifies the warehouse panel by vtable signature, not by panel ID — works correctly even when mods like "No Letterbox" change the UI configuration
[*][b]Safety system:[/b] Hotkey is automatically blocked during cutscenes, minigames, and other unsafe states
[*][b]Configurable:[/b] Hotkey can be changed via INI file
[*][b]Keyboard modifiers:[/b] Optional modifier key support (e.g. Shift+I to open storage while plain I opens inventory)
[*][b]Xbox / XInput controller:[/b] Assign a controller button via XInput. Supports an optional modifier button (e.g. hold LB + press D-Pad). Works with Xbox controllers natively and all other controllers through Steam Input.
[*][b]PS5 / PS4 controller:[/b] Native HID support for DualSense and DualShock 4 — close warehouse with Circle button. Configurable PSButton in INI (Share, Options, Circle, Triangle, Square, Cross, L1, R1, L3, R3, Touchpad, PS, Mute)
[*][b]INI hot-reload:[/b] Press F11 to reload all settings without restarting the game
[/list]

[size=3][b]Installation[/b][/size]

[list=1]
[*]Make sure Ultimate ASI Loader ([b]version.dll[/b]) is in:
[code][Steam]\steamapps\common\Crimson Desert\bin64\[/code]
[*]Copy [b]PrivateStorageAnywhere.asi[/b] and [b]PrivateStorageAnywhere.ini[/b] into the same [b]bin64[/b] folder.
[*]Launch the game. Press F6 to open Private Storage from anywhere.
[/list]

[line]

[size=3][b]Configuration[/b][/size]

Edit [b]PrivateStorageAnywhere.ini[/b]:

[code][Settings]
Enabled=1              ; Master switch (0=off, 1=on)
DebugLog=0             ; Create log file for troubleshooting (0=off, 1=on)
Hotkey=75              ; Keyboard hotkey in hex (default: 75 = F6)
ModifierKey=00         ; Hold this key + Hotkey (00 = no modifier)
ReloadKey=7A           ; Press to reload INI (default: 7A = F11, 00 = disabled)
ControllerButton=0000  ; XInput controller button (0000 = disabled)
ControllerModifier=0000 ; Hold this button first (0000 = no modifier)
PSButton=none          ; PS5/PS4 button: Circle, Triangle, Square, Cross, L1, R1, etc. (none = disabled)[/code]

Key codes use Windows Virtual Key Codes in hex format. A full reference table covering letters, numbers, F1-F24, numpad, navigation, modifiers, punctuation, mouse buttons, and media keys is included at the bottom of the INI file.

[size=3][b]Controller Setup[/b][/size]

To use a controller button, assign a button in the INI:

[code][Settings]
ControllerModifier=0100  ; Hold LB before pressing the button
ControllerButton=0001    ; D-Pad Up[/code]

In this example, [b]LB + D-Pad Up[/b] opens Private Storage.

[b]Controller button values:[/b] DPAD_UP=0001, DPAD_DOWN=0002, DPAD_LEFT=0004, DPAD_RIGHT=0008, START/MENU=0010, BACK/VIEW=0020, LEFT_STICK=0040, RIGHT_STICK=0080, LB=0100, RB=0200, A=1000, B=2000, X=4000, Y=8000

[b]Non-Xbox controllers via Steam Input:[/b] Switch and other non-Sony controllers are supported through Steam Input, which translates them to XInput automatically.

[size=3][b]PS5 / PS4 Controller Setup[/b][/size]

PS5 DualSense and PS4 DualShock 4 controllers are supported natively via HID Raw Input — no Steam Input required. Set a button in the INI:

[code][Settings]
PSButton=Circle[/code]

[b]Supported PSButton values:[/b] Share, Options, Circle, Triangle, Square, Cross, L1, R1, L3, R3, Touchpad, PS, Mute, none

The close action is deferred to button release to prevent triggering a dodge roll in gameplay. Supports DualSense, DualSense Edge, and DualShock 4 v1/v2 over USB and Bluetooth.

[size=3][b]Antivirus Notice[/b][/size]

Some antivirus programs may flag this mod because it relies on low-level hooking to access the game's internal panel functions directly.

Crimson Desert does not provide an official mod API for this functionality, so the mod has to locate and call internal game functions in memory. That kind of behavior can look suspicious to antivirus software even when the mod itself is not malicious.

[line]

[size=3][b]Uninstall[/b][/size]

Delete [b]PrivateStorageAnywhere.asi[/b] and [b]PrivateStorageAnywhere.ini[/b] from the game's [b]bin64[/b] folder. Optionally delete [b]PrivateStorageAnywhere.log[/b] if present.
